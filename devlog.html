Day 1: Web Dev

The first thing I did when starting this was learn some basic HTML and how it works. I'm using Notepad++ for this because it has plugins that help improve the experience and is easy to work with. I've learned about Bootstrap which is a css library and web development framework that allows me to make mockups really easily instead of having to hardcode my own.

I learned how to make a navbar, dropdowns and a hamburger menu. The navbar is the bit at the top that allows people to access different areas of the website. When the screen size is small enough, the navbar brand stays while the rest of the navbar elements are packed into a hamburger menu. The dropdown menus are useful as they store different elements based on the category. They are hiddden by default and shown when the menu is clicked which saves space. This allows me to have complex menus that are space efficient.

Those elements where made with bootstrap but i have also made my own custom elements as well as creating a stylesheet using css to create custom classes and styles. I created download links for Super Mario Bros. and Minecraft which allow you to download games, mods and images for those specific categories.

I made multiple pages such as index.html, download.html and bio.html which I linked together to create the website.

    Day 4: Big Changes with UE5 Game

    I have been working in UE5 to create a survival game. Currently there is only wood and a couple crops. Today we added the ability to harvest crops and made a semi-functional inventory that stores the items. Each item stacks at 50.

  • List of Items:

    • Harvesting Gun

      Wood

      Oak, Birch and Pine Saplings

      Pumpkin w/ Seeds

      Beetroot w/ Seeds

      Melon w/ Seeds

      Potato w/ Seeds

      Wheat w/ Seeds

      Carrot w/ Seeds

    • I have also made a custom temporary material instance for the ground and hills. A material instance allows you to edit parameters of a metrial without effecting the main material. I changed the colours of the material instance to make it look like grass.

  • Temporary Ground:

    • We programmed the inventory system to work by first checking if the slots have the same item as the one harvested, if they do then add the extra to current. If it has reached the cap, add to new slot. If there isn't the same item, it will check the next slot if it's avaliable then add the item to that slot. If there are no spaces left, it currently gives a message telling you it's empty.

  • Inventory/HUD:

    • The crops are just recolored pumpkins with different drops but the models will be changed to fit the crop. There currently three different types of trees: Oak, Birch and Pine. These drop different amounts of wood depending on the type of tree.

  • Drop Amounts:

    • Wood:

      • Oak: 1-5 Wood, 1-3 Oak Saplings
      • Birch: 4-8 Wood, 1-3 Birch Saplings
      • Pine: 7-12 Wood, 1-3 Pine Saplings

      Crops:

      • Pumpkin: 1-11 Pumkins, 1-3 Pumpkin Seeds
      • Beetroot: 1-11 Beetroots, 1-3 Pumpkin Seeds
      • Melon: 1-11 Melons, 1-3 Pumpkin Seeds
      • Potato: 1-11 Potatoes, 1-3 Pumpkin Seeds
      • Wheat: 1-11 Wheat, 1-3 Pumpkin Seeds
      • Carrot: 1-11 Carrots, 1-3 Pumpkin Seeds
